## ✨ 核心特性

### 1. 🧘 沉浸专注阅读
- **杂栏全消**：一键隐藏 X 左右两侧的导航栏、推荐关注、实时趋势与广告噪音，只保留纯粹的推文主信息流。
- **自定义列宽**：支持 `600px` ~ `1200px` 多档宽度自适应调节，提供 `标准`、`舒适`、`沉浸` 三档字号与行距排版。
- **阅读滚动进度**：顶部极细进度条，优雅反馈阅读深度。

### 2. 🔍 Mac Spotlight 极简搜索
- **单行 Pill 药丸设计**：摒弃复杂的搜索面板与无用标签，按下 `S` 键呼出居中药丸搜索框。
- **ESC 极简交互**：单个轻量 ESC 气泡提示，按 `ESC` 键即可秒关搜索框。

### 3. 💼 职场摸鱼与老板键套件
- **高仿真老板键 (`B` 或 `⌥B`)**：一键秒切 1:1 逼真 Google Docs 文档（“2026 Q4 业务架构与跨系统协同方案演进规划”），自动暂停背景视频与音频播放。
- **标签页全套伪装 (Tab Cloak)**：将网页标题与 Favicon 伪装为 Google Docs 图标与文档标题。
- **低调防窥模式**：**默认开启**图片/视频微模糊遮罩（鼠标悬停即刻清晰还原，防同事路过窥屏）；支持推文头像降噪灰度、隐藏刺眼蓝 V 徽标。

### 4. 💎 高信噪比干货专栏 (科技 / 认知 / 搞钱)
- 过滤无效水贴，直接直达经过点赞加权提纯的高质量内容专栏：
  - 🔥 **综合精选**：科技 + 认知 + 搞钱出海高质量混合流
  - 🤖 **科技 & 前沿 AI**：大模型、Cursor、Claude、全栈与独立开发
  - 💡 **提升认知 & 商业思考**：思维模型、底层逻辑与商业模式拆解
  - 💰 **搞钱 & 独立出海**：副业探索、出海产品与真实 MRR 盈利经验

### 5. 🚫 强力清剿币圈垃圾营销
- **双重拦截机制**：
  - **检索层过滤**：自动追加排除词，拦截 Binance、币安、OKX、合约、做空、做多、爆仓、土狗、铭文、空投、代币等推广。
  - **时间线客户端过滤**：内置高频 Spam 正则，秒级移除时间线里伪装成干货的炒币与返佣推文。

### 6. 🎛 悬浮球拖拽与面板实时吸附
- 悬浮控制球支持在屏幕内自由拖拽，松手自动贴边；设置面板与悬浮球位置实时联动吸附，绝不脱节。

## ⌨️ 极客快捷键一览

| 快捷键 | 功能说明 |
| :---: | :--- |
| <kbd>P</kbd> / <kbd>⌥P</kbd> | **展开 / 收起悬浮设置面板**（免鼠标点击） |
| <kbd>J</kbd> | **下一条推文**（平滑滚动并居中聚焦） |
| <kbd>K</kbd> | **上一条推文**（平滑向上跳回上一条） |
| <kbd>S</kbd> | **呼出 Spotlight 极简搜索框** |
| <kbd>B</kbd> / <kbd>⌥B</kbd> | **一键老板键**（切换/恢复 Google Docs 伪装状态） |
| <kbd>F</kbd> | **专注模式开关**（快速切换纯净流 / 完整原版） |
| <kbd>T</kbd> | **回到顶部** |
| <kbd>ESC</kbd> | **快速关闭** 搜索框 / 设置面板 / 退出全屏状态 |

## 🛠 开发者与更新维护

本项目采用**纯原生 Vanilla JS（Zero Dependencies）**，无 Node/Vite 构建负担：

1. **日常修改**：直接在 `x-focus-mode.user.js` 中调整代码。
2. **递增版本**：修改头部 `// @version 1.8.x`。
3. **提交推送**：
   ```bash
   git add x-focus-mode.user.js
   git commit -m "feat: 你的新特性说明"
   git push origin main
   ```
4. **自动更新**：Tampermonkey 检测到远端版本号更新后，会自动静默下载并替换，免去任何手动操作。
