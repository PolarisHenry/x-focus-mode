## ✨ 核心特性

### 1. 🧘 沉浸专注阅读
- **杂栏全消**：一键隐藏 X 左右两侧的导航栏、推荐关注、实时趋势与广告噪音，只保留纯粹的推文主信息流。
- **自定义列宽**：支持 `600px` ~ `1200px` 多档宽度自适应调节，提供 `标准`、`舒适`、`沉浸` 三档字号与行距排版。
- **阅读滚动进度**：顶部极细进度条，优雅反馈阅读深度。

### 2. 🔍 Mac Spotlight 极简搜索
- **单行 Pill 药丸设计**：摒弃复杂的搜索面板与无用标签，按下 `S` 键呼出居中药丸搜索框。
- **ESC 极简交互**：单个轻量 ESC 气泡提示，按 `ESC` 键即可秒关搜索框。

### 3. 💼 职场摸鱼与老板键套件
- **高仿真老板键 (`B` 或 `⌥B`)**：一键秒切 1:1 逼真 Google Docs 文档（“2026 Q4 业务架构与跨系统协同方案演进规划”），自动暂停背景视频与音频播放。
- **标签页全套伪装 (Tab Cloak)**：将网页标题与 Favicon 伪装为 Google Docs 图标与文档标题。
- **低调防窥模式**：**默认开启**图片/视频微模糊遮罩（鼠标悬停即刻清晰还原，防同事路过窥屏）；支持推文头像降噪灰度、隐藏刺眼蓝 V 徽标。

### 4. 💎 高信噪比干货与摸鱼专栏 (全网纯过滤 / 随机跨领域通识 / 科技 / 商业 / 出海)
- 过滤无效水贴与情绪噪音，直达经过点赞加权提纯的高质量内容专栏（默认采用热门 Top 排序）：
  - 🔥 **综合精选**：科技 + 商业深度拆解 + 独立出海高质量混合流
  - 🌊 **纯净漫游 (全网只做过滤)**：全网自由探索不限主题，无币圈推广、无键政吵架、无灰产引流
  - 🧠 **随机知识 (跨领域漫游·无垃圾)**：涵盖物理、天文、宇宙、历史、心理学、脑科学、生物演化、博弈论与生活原理，摸鱼涨姿势最佳伴侣
  - 🤖 **科技 & 前沿 AI**：大模型、Cursor、Claude、全栈开发与开源项目
  - 💡 **商业深度拆解 & 思维模型**：摒弃空洞“认知”口水，聚焦商业模式、决策框架、深度复盘与读书笔记
  - 💰 **搞钱 & 独立出海**：真实 MRR 变现、出海冷启动与实战复盘

### 5. 🚫 三重清剿垃圾：检索过滤 + 客户端正则 + Twitter 官方屏蔽库一键同步
- **三重拦截机制**：
  - **检索层过滤**：自动追加 50+ 排除词，全面拦截 Binance/合约/空投/代币，并**彻底排除“反动/汉奸/走狗/境外势力/批斗”等极端政治口水，以及“梅毒/艾滋/做爱/卖逼/性病/约炮”等黄推低俗骚扰与灰产引流**。
  - **客户端正则过滤**：内置高频 Crypto、政治暴论与黄推/低俗/性病营销三重正则引擎，秒级扫描整张推文卡片（正文、作者昵称与引用），秒级隐藏时间线里伪装的炒币、口水战与低俗推文。
  - **Twitter 官方屏蔽词一键同步**：支持一键将 135+ 个核心垃圾词批量写入你的 Twitter 账号官方屏蔽库（Muted Words），全平台（含手机 App、通知与推荐）永久彻底净化！

### 6. 🎛 纯净悬浮球与全新紧凑多 Tab 设置面板
- **高度缩减 65%**：告别原先动辄 800px+ 顶满全屏的超长界面，创新采用顶级 3-Tab 紧凑分区设计（`🧭 专栏漫游` / `🛡️ 深度过滤` / `⚙️ 界面控制`），单屏高度仅 280~320px，随点随切极速丝滑。
- **纯净悬浮球与智能避让**：纯净毛玻璃圆形悬浮球，默认停靠在右上角搜索按钮左侧；支持在屏幕内自由拖拽；设置面板采用动态避让算法，绝不与悬浮球重叠遮挡。

## ⌨️ 极客快捷键一览

| 快捷键 | 功能说明 |
| :---: | :--- |
| <kbd>P</kbd> / <kbd>⌥P</kbd> | **展开 / 收起悬浮设置面板**（默认停靠在右上角 S 搜索胶囊左侧） |
| <kbd>J</kbd> | **上一页**（平滑向上跳回上一条推文） |
| <kbd>K</kbd> | **下一页**（平滑向下滚动并聚焦下一条推文） |
| <kbd>S</kbd> | **呼出 Spotlight 极简搜索框** |
| <kbd>B</kbd> / <kbd>⌥B</kbd> | **一键老板键**（切换/恢复 Google Docs 伪装状态） |
| <kbd>F</kbd> | **专注模式开关**（快速切换纯净流 / 完整原版） |
| <kbd>T</kbd> | **回到顶部** |
| <kbd>ESC</kbd> | **快速关闭** 搜索框 / 设置面板 / 退出全屏状态 |

## 🛠 开发者与更新维护

本项目采用**纯原生 Vanilla JS（Zero Dependencies）**，无 Node/Vite 构建负担：

1. **日常修改**：直接在 `x-focus-mode.user.js` 中调整代码。
2. **递增版本**：修改头部 `// @version 1.8.x`。
3. **提交推送**：
   ```bash
   git add x-focus-mode.user.js
   git commit -m "feat: 你的新特性说明"
   git push origin main
   ```
4. **自动更新**：Tampermonkey 检测到远端版本号更新后，会自动静默下载并替换，免去任何手动操作。
